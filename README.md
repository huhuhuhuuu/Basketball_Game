# Basketball Shooting Game

A 3D basketball shooting game built in Unity. The goal: your shot only goes in if your real-world shooting form is accurate, detected via webcam.

## Features (planned)

- **Stages:** Free throw, Three pointer (more to come)
- **Modes:** Classic, NBA, PvP
- **Camera:** Toggle between first-person and third-person
- **Pose detection:** Webcam reads your shooting form (elbow, knee, wrist) and scores accuracy

## Build order

1. Outdoor court scene (current step) — court, fence, hoops, benches, props, free camera
2. Click-to-shoot prototype (basic physics, ball)
3. Stages: free throw + three pointer
4. Modes: Classic / NBA / PvP
5. Webcam pose detection (MediaPipe via Unity plugin)

## Tech

- Unity 6 (6000.3), Built-in Render Pipeline, Linear colour space
- C#
- MediaPipeUnityPlugin (planned, phase 5)

## Status: outdoor court scene

`Assets/Scenes/MainScene.unity` contains three objects: **Main Camera** (with `FreeFlyCamera`),
**Directional Light** (the sun) and **CourtBuilder**. Everything else is generated by code when you
press Play — no models or textures are imported; every mesh and texture is built procedurally, so the
project stays tiny and every detail can be tweaked in C#.

What gets built (see `Assets/Scripts/Court/`):

| Module | Builds |
| --- | --- |
| `FloorModule` | Green painted-asphalt slab (21 × 37 m) with aggregate, worn patches, hairline cracks, concrete edge |
| `LinesModule` | Black FIBA markings: boundary, half-court line, centre circle, keys, free-throw lines and semicircles, three-point lines, no-charge semicircles, lane marks, throw-in marks |
| `HoopModule` | Two hoops: gooseneck pole, white backboard with black border and the black shooter's square, orange rim (with collider), nylon net |
| `FenceModule` | 4 m chain-link fence on galvanised posts with top rail, a slightly open gate, one dented panel, rust |
| `BenchModule` | Weathered wooden park benches with cast-iron frames (a missing slat, a broken slat, bird droppings) |
| `PropsModule` | Basketballs in the corner, a dented trash can with overflowing rubbish, an open pizza box with a leftover slice, crushed can, cups, chip bag, bottles, a sports bag |
| `WearModule` | Dirt patches, scratches and scuffs, cracks with a weed, gum spots, a puddle, leaves, rust streaks |
| `SurroundingsModule` | Grass, concrete path from the gate, trees, flood-light poles, bike rack, drinking fountain, hedges |

All dimensions live in `CourtSpec.cs`; all layout decisions (where the benches, gate, trash can and
balls are) live there too, so nothing overlaps.

### Controls (Play mode)

| Input | Action |
| --- | --- |
| `W A S D` / arrows | Move |
| Hold **right mouse button** + move mouse | Look around |
| `E` / `Space` and `Q` / `Ctrl` | Up / down |
| `Shift` | Move faster |
| Mouse wheel | Change move speed |
| `R` | Reset camera to the start view |
| Touch: one finger drag / two finger drag | Look / move |

### Seeing the court without pressing Play

Select **CourtBuilder** in the Hierarchy and click **Build Court** in the Inspector (or use the
`Basketball ▸ Build Court In Scene` menu). The same objects are baked into the scene and the generated
textures/meshes/materials are saved under `Assets/Generated/Court` so you can inspect and move things in
the Scene view. **Clear** removes them again. Changing the `seed` re-rolls the litter, leaves and wear.

### Notes

- The first frame of Play mode takes a few seconds: every texture and mesh is generated on the spot
  (the Console prints how long it took and how many objects were made).
- `Assets/Generated/` (written by **Build Court**) is ignored by git; it is rebuilt on demand, so keep
  the scene un-baked (or run Build Court again after cloning) rather than committing baked assets.
- The earlier shooting / scoring / mobile-controls prototype was removed on purpose; ball movement and
  gameplay will be rebuilt later on top of this scene (the old scripts are still in git history).
- `Standard` is listed under *Always Included Shaders* in Graphics settings because all materials are
  created at runtime; without that, builds would show pink materials.
